# Prototyp: Systems zur datengestützten Problemidentifikation am Beispiel "The Sandbox City: Heidelberg"

Dieses Repository enthält den praktischen Teil meiner Bachelorarbeit. Es handelt sich um eine webbasierte Anwendung zur Vernetzung von Stadtverwaltung, Wirtschaft und Forschung, um Wissensmanagement auf kommunaler Ebene zu optimieren.

## Über das Projekt

Kommunale Herausforderungen erfordern oft komplexe Lösungen. Oft existieren diese bereits in der Forschung oder Wirtschaft, werden aber aufgrund mangelnder Vernetzung innerhalb der Verwaltung mehrfach neu entwickelt. 

Dieser Prototyp adressiert dieses Problem durch:
* **Zentrales Repository:** Erfassung von Projekten und Innovationen in einer strukturierten Datenbank.
* **Vernetzung:** Zuordnung von Experten und Gruppen zu spezifischen Innovationsthemen.
* **Agentenbasierte Suche:** Intelligente Unterstützung bei der Identifikation relevanter Ansprechpartner und Projekte.
* **Akademische Schnittstelle:** Direkte Anbindung von Akteuren aus universitären Einrichtungen.

## Funktionen

- [x] **Projekt-Dashboard:** Übersicht über laufende kommunale Innovationen.
- [x] **Datenbank-Anbindung:** CRUD-Operationen für Projekte und Problemstellungen.
- [x] **Agenten-Modul:** Algorithmus zur Suche und Verknüpfung von Personen und Projekten.
- [x] **Rollenkonzept:** Unterscheidung zwischen Verwaltung, Erfindern und öffentlichen Interessenten.
