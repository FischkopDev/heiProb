# SandboxAddUnitTests

## Description

Unit-Tests für das Anlegen von Sandbox-Projekten (`POST /api/sandbox/add`).
Überprüft die Datenvalidierung des API-Endpunkts sowie die korrekte Speicherung 
und Referenzierung in der Datenbank-Tabelle `Project`.
